# Studio Assets

Real material from Bestman Luxe Studio, supplied by the developer. These may be used on the website and in seed data. They are portrait phone photos (about 650–1020px wide, 1280px tall), so they suit tall mosaic tiles and mobile panels. They are too small for a full-width desktop hero; ask the developer for a larger landscape or interior shot for that.
