# Design Reference

Two sets of references, one per system. They show **feel, structure, and visual language** only. `ui-context.md` describes them in words and is the written source of truth; when the words and pictures disagree, ask the developer.

Never copy text, logos, product names, brand names, or photos from these images.

## `site/` — Public website (from a barbershop template, "DS Barbers")

| File | Shows |
| --- | --- |
| `01-desktop-hero.png` | Black hero with dark imagery, big centered name, circular crest, Book Now, floating nav bar, vertical social rail |
| `02-desktop-services-panels.png` | Two tall full-bleed photo panels with centered title, subtitle, outlined See More, staggered over black |
| `03-desktop-about.png` | Off-white "paper" section: photo left, heavy heading and short text right, solid dark button; mosaic starting below |
| `04-desktop-gallery-mosaic.png` | Gallery mosaic with thin black gutters and mixed tile sizes |
| `05-mobile-hero-and-services.png` | Mobile: centered name, crest, Book Now, then a full-bleed panel |

The template's serif wordmark is replaced by **Bebas Neue** and the studio's own logo.
